# 成员 C 的任务

你负责命令行交互、系统集成和交付整理，让操作者能够按角色完成业务，并能依据说明构建、运行和验证系统。开发分支使用 `member/c/<任务>`，通过 PR 合并到 `main`。界面接口以 [cli.h](../../include/cli.h) 为准，协作流程见 [CONTRIBUTING.md](../../CONTRIBUTING.md)。

## 菜单与业务场景

整理未登录、管理员、卡用户和卡业务员的菜单草案及权限用例。未登录界面提供登录与退出，首次启动提供管理员初始化入口；登录后按角色显示功能，并提供修改本人密码和退出登录。

管理员菜单覆盖创建、查询、列出和删除账号。卡用户菜单覆盖查询本人卡与余额、修改电话、充值和消费。卡业务员菜单覆盖开卡、按学号与姓名查询、冻结和解冻。姓名查询显示全部精确同名结果，不把同名视为唯一记录。

与 B 核对每项操作的服务接口和错误码，与 A 核对工作目录和数据目录。菜单只负责收集输入和展示结果，权限和余额规则由业务接口执行。

## 输入输出与金额

实现 `src/cli.c`，正确处理整行输入、空行、EOF、超长行和换行清理。超长输入排空当前行后提示，避免剩余字符被当成下一次选择。界面使用 UTF-8，明确处理 Windows 控制台编码，并分别验证 Windows 与 macOS。

实现整数金额解析，只接受非负十进制整数或最多两位小数，不接受正负号、指数、逗号、空白或多余字符，检查转换溢出。允许解析零，由业务层拒绝零金额充值与消费。展示金额固定两位小数，全程不使用浮点数计算余额。

密码输入可以回显，但不得主动打印、记录密码或凭据。账号只显示用户名、角色和关联学号。错误提示依据返回码生成，不显示内部绝对路径、密码盐、派生值或堆栈。

为金额解析和输入边界提供独立测试，覆盖整数、一位与两位小数、零、非法字符、格式错误和范围边界。为重复输入、EOF 和超长行提供可复现的检查方法。

## 会话与程序入口

维护 `main.c`，串联存储初始化、CLI 运行和存储关闭，处理启动及退出失败。存储生命周期由入口管理，CLI 内部通过业务服务执行操作，不直接调用存储函数或读写 JSON。

通过认证服务完成首次管理员创建与登录，不预置固定公开密码，不把存储错误视为首次启动。保存登录成功的会话，退出登录时清除；修改密码后会话继续有效。卡用户充值、消费和修改电话时不允许输入其他学号作为目标。

当前入口仅输出占位文本，应以实际程序生命周期替换。与 A、B 约定可链接的交接点，功能未就绪时使用草稿 PR，不用返回固定成功的占位实现冒充已完成业务。

## 系统集成与验收

将 CLI 和入口接入现有构建目标，增加 CLI 冒烟测试及端到端测试，并接入 CTest。协调三人的 CMake 修改，检查正式程序与测试使用一致的后端实现。

使用独立临时目录运行完整场景：首次创建管理员，创建业务员，业务员开卡，管理员创建关联卡用户，卡用户充值和消费，业务员冻结及解冻，卡用户修改电话和密码，管理员删除账号。验证重启后数据仍可读取，删除账号后不能登录且卡记录保留。

覆盖同名多学生查询、错误密码、越权操作、冻结卡资金操作、余额不足、输入错误及损坏文件。对不允许的角色操作同时保留 B 的接口测试与界面验证，不能只检查菜单是否隐藏。

汇总 Windows 与 macOS 的构建、模块测试和集成结果，记录失败现象、复现条件和负责排查的成员。文件和索引问题交 A，数据结构与业务问题交 B，交互和程序串联问题由你处理，修复后复测相关场景。
