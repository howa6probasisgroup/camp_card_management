# 密码处理与测试

密码模块的公共接口见 [password.h](../include/password.h)，长度和派生参数见 [common.h](../include/common.h)。密码长度按字节计算；盐和派生值仅接受指定长度的小写十六进制字符串。

`password_create` 使用 OpenSSL 随机源生成盐，再派生密码；全部成功后才写入两个输出缓冲区。输出容量与互不重叠要求遵循头文件契约。`password_verify` 解码已保存凭据，重新派生后调用 `CRYPTO_memcmp` 比较完整派生值。临时盐和派生值在返回前清理，模块不打印密码、盐或派生值。

空指针和非法密码长度返回参数错误，凭据编码不合法返回数据错误，合法凭据与密码不匹配返回认证失败。随机源和派生调用失败返回 IO 错误；本次 OpenSSL 错误队列含分配失败时返回内存不足。调用 OpenSSL 前清除旧错误，失败后读取并清理本次错误队列，防止把遗留错误当作当前失败原因。

按 [README](../README.md#构建与测试) 配置与构建后，执行：

```sh
ctest --test-dir build --output-on-failure -R '^password(_failures)?$'
```

若使用其他构建目录，将 `build` 替换为该目录。

正常测试覆盖长度边界、UTF-8 字节长度、随机盐重复生成、正确及错误密码、固定向量、凭据长度和非法字符。固定向量检查派生参数，避免只依靠生成与校验互相验证。

故障测试单独编译密码实现，仅在测试目标中替换随机和派生入口，模拟内部 IO 错误、无错误队列的失败及分配失败，并检查创建失败时两个输出缓冲区完整保留原值。正式库始终链接真实 OpenSSL。测试只输出通过状态或失败行号，不输出凭据。

这些测试验证密码模块及错误映射；不验证认证服务、存储持久化或登录流程，也不能代替各平台构建与运行检查。
