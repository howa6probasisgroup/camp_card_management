# 简易校园卡管理系统

基于 C 的课程实践命令行项目，按角色提供账号管理、登录、个人信息修改及校园卡业务。业务数据使用 JSON 文件保存。

小组成员维护各自的开发分支，通过 PR 提交代码；具体流程见 [小组协作约定](CONTRIBUTING.md)。

各成员任务：[成员 A](docs/tasks/a.md)、[成员 B](docs/tasks/b.md)、[成员 C](docs/tasks/c.md)。

## 依赖

- yyjson：JSON 解析与序列化。
- OpenSSL Crypto：随机盐生成及 PBKDF2-HMAC-SHA-256 密码派生。

依赖声明与版本见 [vcpkg.json](vcpkg.json)，构建配置见 [CMakeLists.txt](CMakeLists.txt)。

## 基本契约

- 管理员管理账号；卡业务员开卡、查询、冻结与解冻；卡用户查询自己的卡、修改联系电话、充值和消费。业务接口自行检查权限。
- 学号为固定九位 ASCII 数字，卡号与学号相同；每名学生最多一张卡。开卡余额为零，状态正常。
- 金额以整数分保存，充值与消费必须为正数；冻结卡不能充值或消费，消费不得超过余额，金额运算检查溢出。
- 密码长度为 8—64 字节，使用随机盐与 PBKDF2-HMAC-SHA-256 保存派生值，不保存明文密码。
- 按学号直接定位主记录；按姓名精确匹配 UTF-8 字节并返回全部同名记录。姓名索引是辅助数据，查询结果须核对主记录。
- 存储层统一处理 JSON 与路径，业务层处理规则与授权，CLI 负责输入输出。公共声明及所有权约定见 [include](include/)。
- 文件不存在、数据损坏和读写失败分别返回对应错误；不得把读取失败视为零余额。链表拥有数据副本，由调用方使用对应的清理函数释放结果。

数据目录相对于程序启动时的工作目录，开发与演示从项目根目录运行，测试使用独立临时目录。系统只允许单实例写入，不提供交易流水、并发写入、原子提交、跨文件回滚或崩溃恢复。
